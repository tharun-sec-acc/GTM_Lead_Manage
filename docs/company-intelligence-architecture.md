# Company Intelligence architecture

Company Intelligence is an opt-in domain inside the existing FastAPI, SQLAlchemy, Alembic and Celery application. Its API, models, source adapter, evidence extraction, orchestration and report logic live under `backend/app/company_intelligence/`; it reuses the shared database, Celery app and `app.bedrock.converse_json`.

The flow is request validation and domain normalization, a bounded public-site crawl, persistence of immutable source snapshots, seven role-specific evidence extraction runs, deterministic citation/conflict checks, then a fact-only report. The API returns a job identifier; scraping and extraction run in a Celery worker. Successful role results and their facts remain persisted if another role fails.

The separate research profile is keyed by normalized domain and can link to one existing lead. It never creates or modifies leads. A PostgreSQL advisory lock plus database uniqueness constraints reduce duplicate concurrent work; active and fresh jobs are reused unless a refresh is explicitly requested.

The source adapter tries static HTTP/HTTPS on the confirmed official host first. An opt-in Playwright Chromium fallback handles script-bearing pages with little extracted text. All browser resource traffic is fulfilled through the same pinned Python HTTP broker; direct browser networking and unsupported/external requests are blocked. Connections pin a validated public DNS address and preserve the original TLS SNI and Host header. Redirects are revalidated. Robots policy, page/depth/byte/resource-request budgets, source hashes and cache freshness bound collection. After the official crawl, a keyless discovery engine expands deterministic queries and collects candidates from sitemaps, RSS/Atom feeds, outbound links, references inside collected pages, Wikipedia/Wikidata and SEC EDGAR; it then retrieves a bounded, scored cross-domain set through the same safety envelope. No external search API is required or called. See [autonomous discovery](company-intelligence-discovery.md).
